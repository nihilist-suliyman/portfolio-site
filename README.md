# Suliyman Hossain — Portfolio

Minimal personal portfolio. Dark/light theme, looping video background, floating skill icons.

## Setup

1. Clone or download this repo
2. Add your files to `assets/`:
   - `bg.mp4` — your background video
   - `photo.png` — your portrait photo
3. Push to GitHub and enable **GitHub Pages** (Settings → Pages → Source: main branch, root `/`)

## Files

```
index.html        ← Home / About
skills.html       ← Floating skill icons + Education timeline
projects.html     ← Project cards with "add more" slot
contact.html      ← Photo card + social links
style.css         ← All styling (dark/light themes)
script.js         ← Theme toggle + mobile nav
assets/
  bg.mp4          ← Background video (you add this)
  photo.png       ← Portrait photo (you add this)
```

## Adding Projects

Open `projects.html` and duplicate the `<div class="card">` block before the "Add a project" placeholder. Fill in the title, description, tags, and link.
